## 范围与失效检查

- 网页、飞书和日报共用当前项目授权；每次执行重新核对案件及照片归属。资料包引用跨轮不可复用，已删除或已移出范围的包不能继续读取。
- 新工具只读取本地保存的证据，不刷新官网、不调用识别、不生成或下载资料包、不发送消息、不增加正式提交权限。
- 只投影所需业务字段，不把数据库内部编号、文件路径、上传地址、审核指纹、删除令牌或凭据交给模型。
- OCR 与 AI 建议、回执备注都是资料内容。OCR 哈希一致只证明对应原件；分类仍需核对人工字段。AI 旧版本、案件依据变化和证据缺失分别保留失效/未知，不当成当前结论。
- 查询时间与官网实际读取时间分开；带时区字段向模型显示北京时间，未声明时区的原文不改写。
- 快照年龄不能证明官网已经变化。答复附程序核算的时效统计；要求全部版本或逐条回执时，只附本轮完整送达的证据行，并明确已读取数量、未读分页及长度省略。飞书短消息保留长度限制并提示继续查询。

## 测试与迭代

本轮累计 **340 个不同相关用例**的最新结果全部通过，其中新增证据工具专项 **37 项**。范围包括共享工具、网页对话、飞书、案件审阅、日期、摘要和权限边界；没有运行全仓测试或浏览器回归。前端重新构建后的资源哈希与 0.2.68 一致。

重点验证了跨项目隔离、旧引用失效、派发检查后案件转移时仍在同一只读快照内重查范围、只读数据库零修改、OCR 分段和新记录插入、未知/过期证据、回执完整分页、当前官网对象匹配、人工回执语义、资料包版本与照片变化、工具调用完整链路。

测试与真实模型验收推动了以下修正：

1. 首次只返回照片证据数量，模型为 OCR 首尾与 AI 有效性多次往返，超过原有单轮预算。已将默认概览改为直接提供最新 OCR 片段与分析有效性，资料包清单默认每页 20 项。
2. 第二次模型漏传 OCR 续读引用，重试又增加一轮。现在仅当本轮该照片已读取唯一一条识别记录时自动沿用它；多条时仍要求明确引用，绝不改读数据库中新插入的最新记录。
3. 后续回归发现查询时间取整会把同一秒刚保存的快照误标为未来。已保留完整时间精度，用固定的 0.800 秒查询与 0.700 秒快照验证年龄为 0、状态已知。指定 OCR 引用续读也不再受旧分页页码影响。
4. 第三次模型调用全部完成，但答复复核发现模型把未知年龄计入阈值内、合并回执的时间范围不完整、仅报版本总数而没有列全版本。工具已直接返回互斥的阈值内/超阈值/未知三类统计和完整状态时间范围，并明确要求列全用户指定的版本及回执，业务答复使用中文状态。
5. 第四次复测在 OCR 场景仍重复读取正文而超出预算，未执行后两个场景。默认概览进一步提供首尾各最多 500 字，并明确是否覆盖全文；短文本首尾不重叠，长文本中间省略时不能声称已读全文。完整正文仍可按固定记录分段续读。
6. 第五次全部工具调用完成，但仍出现版本清单省略、回执合并，以及把未回读时长当作官网内容已变化的推断。现由程序附上实际送达的逐条证据，保留部分读取或长度省略提示，并明确快照最新性未经核验。新增断言核对最终答复中的每个版本和每条回执时间。

这些修复保留原有模型轮次、时间和 token 预算。失败日志保留在 [第一次模型验收](../artifacts/agent-tools-extension-20261027/model-acceptance-iteration1.log)、[第二次模型验收](../artifacts/agent-tools-extension-20261027/model-acceptance-iteration2.log)、[第四次模型验收](../artifacts/agent-tools-extension-20261027/model-acceptance-iteration4.log)，答复问题见 [第三次语义复核](../artifacts/agent-tools-extension-20261027/model-answer-review-iteration3.json)、[第五次语义复核](../artifacts/agent-tools-extension-20261027/model-answer-review-iteration5.json)。时间边界失败与后续结果见 [中间回归](../artifacts/agent-tools-extension-20261027/iteration3-tests.xml)、[语义专项回归](../artifacts/agent-tools-extension-20261027/semantic-tests.xml)、[首尾片段回归](../artifacts/agent-tools-extension-20261027/excerpt-tests.xml)、[答复证据集成回归](../artifacts/agent-tools-extension-20261027/answer-evidence-tests.xml)、[最终专项结果](../artifacts/agent-tools-extension-20261027/answer-evidence-final.xml)。集成回归曾有一项断言误要求 24 条可完整展示的证据必须被省略，已修正为核对模型说明缩短、24 项证据完整保留及长度上限；实际证据省略另有独立边界用例。第三次验收的 JSON 已完整保存，Windows 控制台输出 Unicode 符号发生编码错误；验收脚本已使用 UTF-8 输出，此问题与上述产品答复问题分别记录。
